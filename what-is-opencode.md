OpenCode is a free, open-source AI coding agent that connects large language models (LLMs) directly to your local codebase and development environment. Created by Anomaly (the team behind SST) and licensed under MIT, it serves as an open-source, model-agnostic alternative to proprietary tools like Claude Code and Cursor. [1] (https://opencode.ai/), [2] (https://atomicbot.ai/blog/what-is-opencode), [3] (https://opencode.school/), [4] (https://www.youtube.com/watch?v=20vcJmqAr4M&t=39), [5] (https://nimbalyst.com/blog/what-is-opencode/)

Core Capabilities

• Autonomous code and file actions. Beyond simple chat, OpenCode reads and edits project files, executes terminal commands, checks compiler diagnostics via Language Server Protocol (LSP), and creates Git-based snapshots so you can revert changes with /undo and /redo. [1] (https://opencode.ai/), [2] (https://atomicbot.ai/blog/what-is-opencode), [3] (https://nimbalyst.com/blog/what-is-opencode/)
• Multi-surface interfaces. You can interact with it through a Terminal User Interface (TUI), a standalone desktop app (macOS, Windows, Linux), IDE extensions (such as VS Code), a local web UI, mobile apps, or a programmatic SDK. [1] (https://opencode.ai/product), [2] (https://www.youtube.com/watch?v=qLBvYQ8dfdc), [3] (https://www.youtube.com/watch?v=WXffHkvfRpM)
• Model freedom. Unlike vendor-locked agents, OpenCode works with over 75–200+ AI providers—including Anthropic (Claude), OpenAI (GPT), Google (Gemini), and DeepSeek—as well as completely offline local models run via Ollama or LM Studio. [1] (https://opencode.ai/), [2] (https://nimbalyst.com/blog/what-is-opencode/), [3] (https://www.youtube.com/watch?v=qLBvYQ8dfdc)
• Customisation and extensibility. It supports custom sub-agents, reusable Markdown skills (.skill.md), custom slash commands, plugins, and external tool integrations via the Model Context Protocol (MCP). [1] (https://www.youtube.com/watch?v=c2Mf4U8s8f8), [2] (https://opencode.ai/), [3] (https://www.youtube.com/watch?v=WXffHkvfRpM)

Pricing and Access

The OpenCode software is free to download and use. To power the AI behind it, you have several options: [1] (https://www.morphllm.com/what-is-opencode), [2] (https://opencode.ai/)
• Free built-in models. You can start coding immediately using free models without creating an account.
• Bring your own keys or subscriptions. Connect your existing API keys or link active subscriptions like ChatGPT Plus/Pro and GitHub Copilot.
• Optional paid gateways. The creators offer OpenCode Go ($10/month, or $40/month for Go Plus) for curated open coding models, and OpenCode Zen, a pay-as-you-go API gateway for frontier models. [1] (https://opencode.ai/), [2] (https://www.morphllm.com/what-is-opencode)
