# how to set terminal proxy
To make these proxy settings permanent in Ubuntu, you need to add them to your shell's configuration file. Since Ubuntu's default shell is Bash, you should add them to your ~/.bashrc file.

Open your terminal and run the following steps:

## Step 1: Open your configuration file

Open your ~/.bashrc file  your preferred text editor:
```bash
vim ~/.bashrc
```

## Step 2: Add the proxy configurations

Scroll to the very bottom of the file and paste the following lines. Note that for socks configurations, terminal tools typically look for the ALL_PROXY or all_proxy variables:
```bash
# Permanent VPN Proxy Configuration for Codex CLI
export http_proxy="http://127.0.0.1:10809"
export https_proxy="http://127.0.0.1:10809"
export HTTP_PROXY="http://127.0.0.1:10809"
export HTTPS_PROXY="http://127.0.0.1:10809"
export all_proxy="socks5://127.0.0.1:10808"
export ALL_PROXY="socks5://127.0.0.1:10808"
export no_proxy="localhost,127.0.0.1,127.0.0.0/8,::1"
export NO_PROXY="localhost,127.0.0.1,127.0.0.0/8,::1"
```
(Adding both lowercase and uppercase variations ensures compatibility, as different CLI tools look for different cases).

## Step 3: Save and Exit

1. Press :wq to save the file and exit.

## Step 4: Apply the changes

To make the changes take effect immediately in your current terminal window without restarting it, run:
```bash
source ~/.bashrc
```

💡 Quick Verification

You can double-check that the system registered your settings by printing one of the variables:
```bash
echo $https_proxy
```

```bash
curl -I https://google.com
```
If it returns http://127.0.0.1:10809, your permanent setup is complete and Codex CLI will now route through your VPN automatically every time you open a terminal.
